# BKDiablo 100% Complete In-Game Holy Grail Chronicle

This folder provides ready-to-share clean stash files with **100% completion** across all categories in the Diablo II: Resurrected BKDiablo mod in-game Chronicle (Holy Grail) tab for both **Softcore** and **Hardcore**.

## Files
- `ModernSharedStashSoftCoreV2.d2i` — 100% completed Chronicle for Softcore.
- `ModernSharedStashHardCoreV2.d2i` — 100% completed Chronicle for Hardcore.
- `user_chronicle_100pct.json` — 100% completed web explorer state.

## Features
- **100% Uniques**: All 490 unique items unlocked.
- **100% Sets**: All 217 set items unlocked.
- **100% Runewords**: All 117 runewords unlocked (including the secondary mod-template entry for *Revenge* [ID 20562] that caused `???` in D2R when undiscovered).
- **Clean / Blank Save**: All shared stash tabs are completely blank (0 items, 0 gold, no stackables) so users can immediately use it as a reference wiki without personal items cluttering their stash.

## Installation Instructions
1. Close Diablo II: Resurrected if it is currently running.
2. Navigate to your D2R BKDiablo save directory:
   `%USERPROFILE%\Saved Games\Diablo II Resurrected\Mods\BKDiablo\`
3. **Backup your existing stash**:
   - For Softcore: Rename `ModernSharedStashSoftCoreV2.d2i` to `ModernSharedStashSoftCoreV2.d2i.bak`.
   - For Hardcore: Rename `ModernSharedStashHardCoreV2.d2i` to `ModernSharedStashHardCoreV2.d2i.bak`.
4. Copy `ModernSharedStashSoftCoreV2.d2i` and/or `ModernSharedStashHardCoreV2.d2i` from this directory into your save folder.
5. Launch Diablo II: Resurrected, open the shared stash, and switch to the **Chronicle** tab to explore all items, runewords, and stats!

# BKDiablo Pre-buff Protected Items

These items stay shared by default and are excluded from bulk mule packing. The rule applies independently in Hardcore and Softcore mode.

## Named protections

- **Call to Arms (CTA)** and an identified BKDiablo equivalent that grants Battle Orders, Battle Command, or Shout.
- **Spectral Shard**, including its BKDiablo name or code variants.
- **Memory** staff, when used for Energy Shield pre-buffing.
- **Demon Limb**, when used for Enchant charges.
- **Treachery**, when used for Fade pre-buffing.
- **Naj's Puzzler** or another explicitly identified teleport-charge swap item.
- **Harmony** or another explicitly identified Vigor-charge swap item.
- A user-added named item or exact item seed that is deliberately designated as shared utility equipment.

Names are only a seed list. BKDiablo item names and variants can change, so the property rule below is authoritative.

## Classification rule

Skill bonuses alone do not make an item protected. `+All Skills`, `+Class Skills`, `+Skill Tab`, oskills, and item-granted auras remain eligible for their ordinary Unique, Set, Runeword, Crafted, Jewelry, Charm, or Base category unless the item is on the named list or the user explicitly adds it.

## Review and override

The bulk preview should show protected items with their source file, tab, item seed, quality, and matching named rule. Users can remove a named item or add a specific item/seed for the current edit session. These changes are never global unless the user saves the mule assignment list.

Runes, gems, and crafting materials are handled separately: they remain in stacked stash tabs and are never candidates for mule packing, regardless of these skill properties.
